# Results

This folder stores handoff artifacts created by the staged prompt workflow.

Each prompt writes to its matching subfolder:

- `01_source_facts`: extracted source facts
- `02_behavior_oracles`: test strategy, fixture candidates, and optional golden-oracle plan
- `03_implementation_semantics`: language-neutral implementation semantics
- `04_EDT_strategy`: distance transform parity and browser replacement decision
- `05_final_spec`: final transferable ridge algorithm document
- `06_review`: adversarial review findings
