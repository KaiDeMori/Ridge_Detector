# Medial Axis Test Oracle Designer

## Task

Design the test and oracle strategy for translating `skimage.morphology.medial_axis` into JavaScript/browser code.

Use the shared orientation first:

- `../shared/medial_axis_orientation.md`
- `../shared/result_contract.md`

Use the source fact table:

- `../results/01_source_facts/source_fact_table.md`

Write the result to:

- `../results/02_behavior_oracles/test_oracle_design.md`

## Scope

Create a test plan that protects the source translation. This step can be completed from source facts alone. Golden output fixtures from a live scikit-image runtime are useful later, but this prompt should provide value before that runtime exists.

## Required Test Groups

Cover these groups:

- source-contract tests for input normalization and output promotion
- 3x3 bit-layout tests
- keep-table tests for representative 512-entry patterns
- component-count tests using 8-connectivity
- cornerness lookup tests
- processing-order tests for distance, cornerness, and tiebreaker priority
- thinning-loop tests for forced center bit and mutable neighbor reads
- boundary tests for 3x3 operations
- EDT strategy tests that can be filled in after step 04
- integration-shape tests for rectangles, squares, disconnected components, holes, and tie-heavy shapes
- optional golden-fixture plan for a future scikit-image runtime

## Required Distinctions

Classify every test as one of:

- **unit source-contract test**: checks a local translation of source mechanics
- **integration behavior test**: checks the full ridge pipeline on a small mask
- **golden oracle test**: compares against output generated by the reference scikit-image runtime
- **project convention test**: checks behavior chosen by this project beyond strict source behavior
